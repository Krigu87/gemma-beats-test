# 🎵 Gemma Beats Spezial
Dein mobiles Rhythmus-Spiel – spiele zu deiner eigenen Musik!

### 🚀 Direkt im Browser spielen
👉 https://krigu87.github.io/gemma-beats-test/

---

## 📲 Als App installieren (Empfohlen)
Für das beste Spielerlebnis (Vollbildmodus ohne Browserleiste und dauerhafte Speicherung deiner Songs & Highscores):

### **Für Android (Chrome)**
1. Link in **Google Chrome** öffnen.
2. Oben rechts auf das **Drei-Punkte-Menü** tippen.
3. **"App installieren"** oder **"Zum Startbildschirm hinzufügen"** wählen.

### **Für iPhone & iPad (Safari)**
1. Link in **Safari** öffnen.
2. Unten auf das **Teilen-Symbol** (Viereck mit Pfeil nach oben ⬆️) tippen.
3. Nach unten scrollen und **"Zum Home-Bildschirm"** wählen.
4. Oben rechts auf **"Hinzufügen"** tippen.

---

## 📂 Eigene Songs laden
Das Spiel unterstützt **MP3**, **M4A**, **AAC**, **WAV**, **OGG** und **FLAC**.

* **Auf Android:** Auf „Neuen Song laden“ tippen und Musikdatei direkt aus dem Dateimanager auswählen.
* **Auf iPhone / iPad:** Song in der Apple „Dateien“-App speichern (z. B. unter Downloads oder Auf meinem iPhone), danach im Spiel auf „Neuen Song laden“ tippen und die Datei auswählen.

---

## 🎸 Features
* **Smarte Beat-Erkennung:** Automatische Takterkennung für jeden beliebigen Song.
* **Lokale Song-Bibliothek:** Deine Songs & Highscores bleiben sicher auf deinem Gerät gespeichert.
* **Challenge Modus:** Lustige Mini-Aufgaben für die Extra-Portion Spielspaß.
* **PWA & Offline:** Blitzschneller Start direkt von deinem Homescreen.
